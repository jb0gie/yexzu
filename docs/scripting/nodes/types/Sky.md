# Sky

The `Sky` node controls the environment's skybox, lighting, and fog.

### `.bg`: String

The background color or image URL.

### `.hdr`: String

The URL of the HDR environment map.

### `.rotationY`: Number

The Y-axis rotation of the skybox in radians.

### `.sunDirection`: Vector3

The direction of the sun light.

### `.sunIntensity`: Number

The intensity of the sun light.

### `.sunColor`: String

The color of the sun light.

### `.fogNear`: Number

The distance where fog starts.

### `.fogFar`: Number

The distance where fog is fully opaque.

### `.fogColor`: String

The color of the fog.
